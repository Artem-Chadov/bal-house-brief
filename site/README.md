# Bal House — многостраничный сайт

Статический сайт без сборки. Откройте через обычный локальный сервер либо разместите папку целиком на GitHub Pages. Главная — index.html. Общие стили и поведение — assets/site-v3.css, assets/site-v3.js.

Материалы проверены 09.10.2026 в открытом сообществе https://vk.ru/balhouse и пяти карточках каталога. Фотографии стройки BL-130: https://vk.ru/wall-223841683_117; BL-5: https://vk.ru/wall-223841683_119. КД-54 и две планировки: https://vk.ru/wall-223841683_43. Изображения проектов взяты из каталога компании, строительные фотографии — из её публикаций. Сгенерированные изображения не используются.

Площадь BL-154 — 125 м² по описанию. Площадь BL-130 не указана из-за повреждённого текста источника. Цена помечена как цена каталога, комплектация уточняется. Отзывы, гарантии, статистика и срок строительства не выдумывались.

Запрос расчёта копируется в буфер обмена. Пользователь сам открывает VK и отправляет сообщение. Серверной отправки, аналитики, localStorage и внешних CDN нет. Личные ответы из анкеты не включены.

Стоимость и комплектацию уточняйте при расчёте. Запрос отправляется пользователем в личные сообщения Bal House в VK. Исходная анкета в корне репозитория сохраняется отдельно.


Первый экран и блок обсуждения используют фотографию на весь фон. Крупные открытые исходники VK сохранены в WebP; для первого экрана, направлений, карточек и главного баннера есть AVIF с резервным WebP. На телефоне главная показывает проекты в ленте с кнопками и ручным перелистыванием, без автоматического движения.

Шрифты Prata и PT Sans размещены локально; проверены русские буквы, типографские знаки и знак рубля. Лицензии OFL лежат в assets/fonts. GSAP3.15.0 размещён локально, copyright сохранён в assets/gsap.min.js; условия: https://gsap.com/standard-license. Анимация первого экрана и галереи отключается при prefers-reduced-motion. Без JavaScript содержание и прямые контакты доступны.
