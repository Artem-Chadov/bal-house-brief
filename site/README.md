# Bal House — предварительная многостраничная версия

Статический сайт без сборки. Откройте через обычный локальный сервер либо разместите папку целиком на GitHub Pages. Главная — index.html. Общие стили и поведение — assets/site.css, assets/site.js.

Материалы проверены 09.10.2026 в открытом сообществе https://vk.ru/balhouse и пяти карточках каталога. Фотографии стройки BL-130: https://vk.ru/wall-223841683_117; BL-5: https://vk.ru/wall-223841683_119. КД-54 и две планировки: https://vk.ru/wall-223841683_43. Визуализации взяты из карточек компании и подписаны. Сгенерированные изображения не используются.

Площадь BL-154 — 125 м² по описанию. Площадь BL-130 не указана из-за повреждённого текста источника. Цена помечена как цена каталога, комплектация уточняется. Отзывы, гарантии, статистика и срок строительства не выдумывались.

Запрос расчёта копируется в буфер обмена. Пользователь сам открывает VK и отправляет сообщение. Серверной отправки, аналитики, localStorage и внешних CDN нет. Личные ответы из анкеты не включены.

Перед коммерческим запуском нужно подтвердить комплектации, актуальные цены и характеристики, права на публикацию материалов, окончательный домен и выбранный способ приёма заявок. Демо закрыто от индексации.
