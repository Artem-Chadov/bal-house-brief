# Бриф Bal House

Статическая анкета из трёх шагов для обсуждения разработки сайта. Откройте `index.html` в браузере или опубликованную страницу GitHub Pages.

Ответы обрабатываются только в браузере. В анкете нет отправки на сервер, аналитики или внешних библиотек. «Скопировать ответы» формирует текст для личной пересылки в VK. «Скачать TXT» даёт резервный файл.

Сохранение черновика выключено по умолчанию. При включении данные хранятся в `localStorage` этого браузера; отключение удаляет черновик. Контакты и направления из предыдущего брифа требуют отдельного подтверждения и доступны для изменения.

Публичный репозиторий содержит код, логотип и текст анкеты с предварительными сведениями о компании. Заполненные ответы не записываются в репозиторий. Для публикации: Settings → Pages → Deploy from a branch → main → /(root).
